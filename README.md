# Telegram-бот для оценки риска депрессии у студентов

Лабораторная работа №3 по дисциплине «Обработка данных в интеллектуальных
и киберфизических системах», 3 курс, 2 семестр.

## Задача
Telegram-бот, который в форме свободного диалога опрашивает студента
и оценивает риск депрессии с помощью модели машинного обучения.

## Данные
Датасет [Depression Student Dataset](https://www.kaggle.com/datasets/ikynahidwin/depression-student-dataset)
содержит 502 анкеты студентов. В нём есть пол, возраст, академическая
нагрузка, удовлетворённость учёбой, продолжительность сна, питание,
часы учёбы, финансовый стресс и наследственность.

## Модель
Random Forest с подбором параметров через GridSearchCV. Текстовые ответы
анкеты перед обучением переведены в числа.

## Агент
Агент построен на LangGraph, в качестве LLM используется gpt-oss-20b
через OpenRouter. Вместо готовой анкеты бот ведёт обычный диалог.
Из ответов пользователя LLM извлекает значения признаков, на которых обучена модель,
проверяет их корректность и задаёт вопросы о недостающих.
Когда все признаки собраны, они передаются в Random Forest, и бот
сообщает оценку риска, после чего можно продолжить общение.
Бот написан на aiogram и поддерживает команды /start, /help и /stop.

## Структура
- `model_training.ipynb` обучение модели
- `llm_client.py` агент на LangGraph
- `bot.py` Telegram-бот
